#  Secure Password Generator Using Python

A simple and secure password generator developed using Python.

## Features
- Generates random passwords using Python's `secrets` module.
- Supports uppercase and lowercase letters.
- Includes numbers and special characters.
- Allows users to choose their password length.
- Requires a minimum length of 8 characters.
- No external libraries required.

## Technologies Used
- Python 3
- Secrets Module
- String Module

## How to Run

1. Install Python 3.
2. Download `PasswordGenerator.py`.
3. Open a terminal in the project folder.
4. Run:

   `python PasswordGenerator.py`

5. Enter your desired password length.
